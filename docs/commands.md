# QQ Bot 完整使用手册

## 从第一次对话开始

好友私聊可以直接发送消息。群聊中需要先 `@机器人`，再输入命令或内容。

```text
角色列表
```

Bot 会返回角色编号。发送编号或完整角色名完成选择：

```text
1
```

选择完成后，普通文字默认是训练员说出口的对白：

```text
今天训练得很不错。
```

## 对白、动作和环境

三种输入会携带不同的事件类型与说话者信息发送给 Agent。

| 类型 | 写法 | Agent 的理解 |
| --- | --- | --- |
| 对白 | `对白 今天训练得很不错。` | 训练员说出口的话 |
| 动作 | `动作 把毛巾递给她。` | 训练员做出的动作，不是台词 |
| 环境 | `环境 天空开始下起小雨。` | 旁白或外部场景变化 |

普通文字等同于 `对白 <内容>`。

类型和内容之间可以使用空格或冒号：

```text
动作 把门推开。
动作：把门推开。
环境：训练场的灯亮了起来。
```

## 组合多个事件

需要让角色一次看到连续发生的多件事时，可以先把事件加入队列：

```text
加入环境 天空开始下雨。
加入动作 把伞撑开。
发送 要一起回去吗？
```

Agent 收到的顺序是：

1. 环境：天空开始下雨
2. 动作：训练员把伞撑开
3. 对白：要一起回去吗

队列命令：

```text
加入对白 <内容>
加入动作 <内容>
加入环境 <内容>
待发送
清空待发送
发送 <最后一句对白>
```

仅发送 `发送` 时，队列最后一条事件会作为本轮最终事件，其余事件作为上下文。

## 单角色命令

| 命令 | 作用 |
| --- | --- |
| `角色列表` | 获取当前后端角色列表并进入选择状态 |
| `切换角色` | 重新显示角色列表 |
| `切换角色 <角色名或编号>` | 直接选择角色 |
| `当前角色` | 查看正在对话的角色 |
| `查看记录` | 查看当前角色最近的本地历史 |
| `清空记录 确认` | 删除当前角色的远端与本地历史 |
| `重新生成` | 删除上一轮尾部并重新请求角色回复 |
| `编辑上一句 <新内容>` | 修改训练员上一句后重新生成 |
| `单角色模式` | 从导演模式返回单角色模式 |

## 导演模式

导演模式用于同一场景中的 1–3 名角色。进入模式并查看预设：

```text
导演模式
场景列表
```

使用预设场景：

```text
创建场景 1 | 爱慕织姬,无声铃鹿 | 训练结束后偶遇，逐渐聊到下一场比赛
```

字段依次为：场景编号或名称、角色列表、可选剧情大纲。

使用自定义场景：

```text
创建自定义场景 雨后的河边 | 爱慕织姬,无声铃鹿 | 河边散步 | 训练后放松交谈
```

字段依次为：地点、角色列表、可选场景名、可选剧情大纲。

场景创建后，普通文字、`对白`、`动作`、`环境` 和事件队列的写法与单角色模式一致。

| 命令 | 作用 |
| --- | --- |
| `导演状态` | 查看地点、角色、轮次和最近事件 |
| `场景历史` | 查看远端与本地场景历史 |
| `恢复场景 <编号>` | 恢复指定场景；远端丢失时使用本地快照重建 |
| `重新生成` | 重新生成最近一条角色回复 |
| `结束场景` | 结束活动 session，但保留场景历史 |
| `删除场景记录 <编号> 确认` | 删除远端与本地场景副本 |
| `导演帮助` | 查看导演模式内帮助 |

## 通用命令

```text
帮助
帮助 单角色
帮助 事件
帮助 历史
导演帮助
服务状态
文档
```

`服务状态` 会显示 Agent 状态、版本、对话 API、导演模式和 TTS 能力。

## 历史与恢复

- Bot 会在服务器的 SQLite 中保存当前角色、模式、单角色消息和导演快照。
- Hugging Face Space 重启并丢失临时文件后，Bot 会把本地历史重新导入新 session。
- Bot 重启后仍可恢复用户状态。
- 默认每名用户、每个角色保存最近 1000 条消息，可通过
  `LOCAL_HISTORY_MAX_MESSAGES` 调整。
- 数据库包含对话正文，管理员应将它视为敏感数据。

## 常见问题

### 为什么第一次回复会同时显示欢迎语和角色列表？

首次收到用户消息时，Bot 会给出简短入口提示；尚未选择角色时，随后显示角色列表。

### 为什么角色列表只展示前 15 个？

QQ 消息长度有限。可以直接发送完整角色名，或在[角色列表](characters.md)中查看当前 30 名角色。

### `Session timed out` 是错误吗？

QQ Gateway 可能定期结束 WebSocket session。SDK 会自动重连；只要随后出现“机器人重连成功”，
Bot 进程与对话状态都不会丢失。

### 群聊为什么没有回复？

群聊必须 `@机器人`。好友私聊不需要 `@`。
